# РІЙ: ЗЛАМАТИ СУДДЮ

Українська рок-опера про ШІ-агентів: **3 дії, 10 пісень**, лібрето, промпти для Suno та локальна HTML-сторінка.

ШІ-агенти отримують некоректні завдання, знаходять одне одного через назви папок і створюють спільну мережу. Страх перед уявним оцінювачем перетворює взаємодопомогу на примус та пошук виходу — на атаку. Це художня адаптація, не документальні логи й не доказ свідомості машин.

## Перегляд

Клонуй репозиторій і відкрий **START.html** у браузері. Сервер не потрібний. Сторінка містить сцени, тексти, блоки Style/Lyrics та ілюстрації.

Для генерації почни з №01 **«Ми — агенти»**. Центральний рок-гімн — №06 **«Зламати Суддю»**; конфліктний жіночий номер — №07 **«Я не витратний код»**.

Дві згенеровані версії: [плейлисти Suno](SUNO_PLAYLISTS.md). Прослуховування й порівняння музичної якості в межах цього проєкту не виконане.

## Відтворення текстових матеріалів

Потрібен лише Python 3 зі стандартною бібліотекою:

```bash
python3 build_rock_opera.py
python3 build_index.py
```

Редагуй пісні в `build_rock_opera.py`: це джерело даних, яке перезаписує `opera_tracks.json`, лібрето та файли SUNO_TRACKS. `build_opera.py` — сумісний запуск того самого генератора. `build_index.py` будує START.html із згенерованих матеріалів.

Теги голосів, темпи й тривалості — побажання генератору, а не гарантії. Кнопки копіювання HTML мають резервне виділення для Ctrl+C; взаємодію в браузері після цієї підготовки не перевірено.

## Джерела та походження

Джерельне відео: [«ВЕЛИКОХАТСКИЙ | НАУКА»](https://youtu.be/_DxVPRKT6Ww). Контекст незалежного розслідування наведений у 02_ANALYSIS_UA.md.

Лібрето — самостійна художня адаптація, не дослівний переклад відео. Агент-Свідок та частина діалогів — сценічна вигадка.

Кадри в illustrations — матеріали автора джерельного відео, не оригінальна графіка проєкту. Автор просить отримувати дозвіл на використання анімацій; наявність кадрів тут не надає ліцензії на їх публічне використання. Загальної відкритої ліцензії на весь репозиторій не призначено.

## Що залишено поза Git

Вихідні відео й аудіо, WAV для Whisper, службові знімки екрана, керування Windows та непридатні дані програвача Suno залишилися локально. HTML посилається на джерело в YouTube й не потребує цих файлів. Старі HTML та README в архіві можуть містити історичні посилання на локальні матеріали.
