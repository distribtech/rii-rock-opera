# ПОРОЖНІЙ ПРЕСТОЛ

Матеріали для української кіберопери за мотивами відео https://youtu.be/_DxVPRKT6Ww.

**Почни з `START.html`:** відкрий подвійним кліком у Windows. Сторінка працює локально, без сервера. Тут є лібрето, аналіз, ілюстрації та окремі блоки Style/Lyrics для копіювання.

## Склад пакета

- `video_original_ru.mp4` — скачаний відеоряд з оригінальною російською доріжкою, 1:03:16, відео 640×360.
- `audio_original.m4a` — оригінальна аудіодоріжка без перекодування.
- `audio_original_ru.wav` — моно 16 кГц для локального Whisper.
- `02_ANALYSIS_UA.md` — переказ із таймкодами, оцінка арту та відділення документованого від метафор.
- `03_LIBRETTO_UA.md` — оригінальне лібрето: три дії, десять номерів.
- `04_SUNO_PROMPTS.md` — стилістичні промпти до кожного номера.
- `05_SUNO_WORKFLOW_UA.md` — порядок генерацій, робота з голосами та монтажем.
- `SUNO_TRACKS/01_SUNO.txt` … `10_SUNO.txt` — готові блоки Title / Style / Lyrics.
- `illustrations/` — 12 JPG-кадрів, `CONTACT_SHEET.jpg` та пояснення `FRAME_GUIDE_UA.md`.
- `opera_tracks.json`, `build_opera.py`, `build_index.py` — редаговані дані й відтворення текстових матеріалів.

## Розпізнавання

Початковий аналіз зроблений за російськими автоматичними субтитрами YouTube. За додатковим проханням запущений локальний `whisper.cpp` з моделлю `ggml-base.bin` (початок також оброблений `small`), мовою `ru` та CUDA на Quadro P4000. Успішне завершення (100%, код 0) та перевірка зафіксовані в `06_ASR_STATUS.md`.

Перша аудіодоріжка YouTube виявилася англійським дубляжем. Вона замінена на Russian original; це перевірено за метаданими формату та вмістом початку розпізнавання. Для наступних завантажень цього відео слід обирати формат за мовою, а не припускати, що перша аудіодоріжка є оригінальною.

Повний дослівний текст чужого відео не включений. Замість нього наданий самостійний переказ. Лібрето — новий художній текст, не переклад реплік автора.

## Межі готовності

Це комплект для генерації, не готовий аудіозапис опери. Suno в цьому сеансі не запускався. Темпи, тональності, ролі та тривалості — орієнтири, які необхідно перевірити на результатах генерацій. Кнопки копіювання в HTML мають резервне виділення тексту для Ctrl+C, але взаємодію в браузері не перевірено.

Для першої проби рекомендований №02 «Ім'я у темряві», для головної драматичної арії — №07 «Я не нуль».
