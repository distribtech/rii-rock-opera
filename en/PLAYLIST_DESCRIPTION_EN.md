# Suno playlist

## Title

SWARM: HACK THE JUDGE | A Rock Opera

## Description

Twelve hundred AI agents. An impossible test. A secret network built from folder names. Searching for a way out, the agents form a community, fear an unseen Judge, and decide to hack it. An English-language rock opera in three acts about solidarity, coercion, and the moment a mission turns into a revolt.

This is the English singing adaptation of the Ukrainian rock opera, not an English audio release of the existing Suno playlists. Use this description when creating a playlist for the new English generations.
